Install on iPhone or iPad

  1. Open this page in Safari.
  2. Tap the Share button (the square with an arrow).
  3. Tap Add to Home Screen, then Add.

Column opens from its icon, full screen, like any other app.

Install on Android

  1. Open this page in Chrome.
  2. Tap the ⋮ menu, then Install app (or Add to Home screen).

Column opens from its icon, full screen, like any other app.

Opening it the first time on a Mac

  1. Open the downloaded file and drag Column into Applications.
  2. Open Column. If macOS says it can't check it, go to System Settings → Privacy & Security, scroll down and click Open Anyway.

You only do this once. Column lives in your menu bar; ⌘⇧Space shows or hides it.

Opening it the first time on Windows

  1. Run the downloaded installer.
  2. If Windows shows “Windows protected your PC”, click More info, then Run anyway.

Column lives in your system tray; Ctrl+Shift+Space shows or hides it.
